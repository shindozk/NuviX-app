# Winlator Input & Controls Configuration Files

This directory contains all default input/control/gamepad configuration files from the Winlator project.
Source: https://github.com/brunodev85/winlator

## Files

| File | Path in Repo | Purpose |
|------|-------------|---------|
| `profile.xml` | `app/src/main/assets/profile.xml` | Main input profile (keyboard + mouse layout) |
| `input-controls.xml` | `app/src/main/assets/input-controls.xml` | On-screen controller/button layout |
| `gamepad-controls.xml` | `app/src/main/assets/gamepad-controls.xml` | Physical gamepad button mapping |
| `controls_keyboard.xml` | `app/src/main/assets/controls_keyboard.xml` | Keyboard layout (alternative) |
| `controls_gamepad.xml` | `app/src/main/assets/controls_gamepad.xml` | Gamepad layout (alternative) |
| `controls_xinput.xml` | `app/src/main/assets/controls_xinput.xml` | XInput controller layout |
| `XInputController.java` | `app/src/main/java/com/winlator/inputcontrols/XInputController.java` | XInput controller model |
| `ExternalControllerBinding.java` | `app/src/main/java/com/winlator/inputcontrols/ExternalControllerBinding.java` | External controller binding model |
| `InputControls.java` | `app/src/main/java/com/winlator/inputcontrols/InputControls.java` | Input controls manager |
| `GamepadState.java` | `app/src/main/java/com/winlator/inputcontrols/GamepadState.java` | Gamepad state model |
